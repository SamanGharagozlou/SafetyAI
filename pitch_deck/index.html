Safety monitoring and assurance layer

The robot must adapt to the people around it.

Monitor.Predict.Alert.

ROBOT STACK
›
INDEPENDENT JETSON EDGE LAYER
›
FLEET OPERATOR ALERT

Independent monitoring alongside the robot’s main stack

SEPAZU

"A robot in a clear area can operate with its available capabilities. Around people, its behaviour must be more restricted. During the hackathon, we added an independent Jetson computer running at the edge beside the robot's main stack. It monitors robot state and intent, predicts potentially unsafe next states, flags anomalies, and alerts the fleet operator. This is our safety monitoring and assurance layer."

Say monitor, predict, flag, alert. Never: certified, fail safe, prevents accidents. Confirm whether the restricted state is enforced on the robot in the demo or only flagged; reword the right panel if it only alerts.
