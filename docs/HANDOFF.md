## 7. Pitfalls we hit
* `~/.local` NumPy 2 breaks ROS's cv2/cv_bridge: run ROS nodes with `PYTHONNOUSERSITE=1` (the launch files do), but then user-site packages like `websockets` are invisible too.
* `depth.launch.py` sets `D1_DEPTH_VENV` itself; in the container `/root/d1_depth_venv` must point to `/opt/d1_depth_venv`.
* After "Clear all" wait ~10 s before loading a map again (old Nav2 nodes still shutting down caused one failed start).
* `pkill -f <pattern>` can kill your own shell; use exact PIDs.
* `git push` from the PC needs `git -c credential.helper= -c credential.helper='!gh auth git-credential'` (git has no helper there); `pytest` needs `-p no:anyio`.
* RTAB-Map `/map` is not latched after data stops (monocular path only).
